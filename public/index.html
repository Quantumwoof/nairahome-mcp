    What's real, and how to connect your own MCP client
    • Real: every answer is a tools/call to the NairaHome MCP server (spec 2025-11-25, Streamable HTTP) shown in the log above. The naira rate is the live mid-market reference from ExchangeRate-API, with its timestamp.
    • Real: the card on the display is the server's MCP App (ui://nairahome/card.html), fetched with resources/read and hosted here the way a multimodal device would host it.
    • Simulated: Alexa+'s language model. A small rule-based intent router in public/app.js picks the tool and fills arguments. It is deliberately simple; in Alexa+, the model reads the tool descriptions and does this.
    • Never invented: provider rates. You tell NairaHome what your app offers; it prices that against the live rate. NairaHome never moves money.
    • Sample data: “load the sample family” fills a clearly labelled demo household.
